What’s changed

Recent releases, newest first. Removed engines listed below are historical changes, not current features.

v57c GRAIN, closer to hand
  • IMPROVED GRAIN is the second engine in the browser, immediately after Prophet.
  • FIXED SOURCE A/B preset selection advances one preset per encoder detent, with or without FINE.
v57b Memory margin restored
  • FIXED Preset and graphics caches use available ordinary RAM, restoring the required 8 KiB of POOL headroom.
  • PRESERVED All 64 USER presets, 30 loop slots and full GRAIN audio buffers are retained.
v57 Meet the two sides of GRAIN
  • NEW Actual A/B buffer waveforms, source engine and preset names, generation status, Position cursor and blend display.
  • NEW Factory-preset capture from Prophet, FM6, SWARM, CLUSTER, CLOUD, VA, FM TONE, PHASE and BASS, plus eight Original source families.
  • IMPROVED GRAINS and TEXTURE pages separate playback controls; SOURCE A/B occupy the former FILTER section.
  • REMOVED GRAIN's filter DSP and filter modulation destinations. Existing filter settings no longer colour GRAIN patches.
  • IMPROVED Smaller graphics buffers and lossless glyph-cache packing reduce POOL use while preserving tested pixels.
v56 A simpler engine list
  • REMOVED DRIFT and WAVE TERRAIN, including their Morph source choices. Stored engine IDs remain reserved.
  • FIXED Opening SAVE dismisses the temporary message that could cover Init preset.
v55 GRAIN joins more chords!
  • NEW Two generated audio source buffers for GRAIN, with parameters saved in USER presets; the initial native sources were Prophet and FM6.
  • NEW 64 compatible FM6 factory sounds imported from the selected FM1 SysEx bank.
  • IMPROVED VA uses four chord voices on CPU0 and two on CPU1. Bass follows note velocity during legato changes.
  • REMOVED TINES, VECTOR and CZ-1. Their stored IDs remain reserved.
v54 More musical randomization
  • IMPROVED Preset randomization focuses on timbre and avoids disruptive pitch changes while protecting native LFO and modulation settings.
  • FIXED Clearer Init preset access in SAVE and a smoother VA note start.

Install from your browser

  1. Fully charge the FM1, connect it directly by USB and keep the computer awake.
  2. Open the installer in a desktop browser with Web MIDI SysEx support. Close your DAW or other apps using the FM1.
  3. The page checks the published firmware file. Press Connect & install and allow MIDI SysEx access.
  4. Keep the downloaded backup. Leave the page open and the FM1 connected until the update completes.

The firmware package matches the v57c file checked with the command-line installer. Browser update tests use simulated devices; a physical FM1 browser update remains to be verified.

Backup, restore and sound files

The installer includes backup/restore and a 64-slot USER sound librarian. Export, import, rename or delete supported sounds; FM6 also supports compatible SysEx files. These are separate from the device’s on-board factory-preset selection. The browser does not upload your backup or SysEx files to a server.

Returning to the original firmware

The installer includes a return-to-stock section. Supply your own unmodified official M-VAVE V15 file; its known SHA-256 is checked locally. Official firmware is not bundled. Some firmware families are refused by the upstream compatibility check; read the installer’s explanation before proceeding.
